# 小手机兼容改进版

基于上游 `fc65539c8494b9328ea76c1e557ec12b168e24bc`，发布在 `main` 与 `codex/phone-compatibility`。

本版保持小手机自己的预设与聊天逻辑，不导入酒馆预设，也不运行酒馆插件脚本。

## 使用

- **角色卡**：在角色界面导入酒馆 V2/V3 JSON 或 PNG 卡。人设、性格、场景背景和对话示例转换为手机角色资料；头像随 PNG 导入。原始开场白、系统提示和扩展数据保留在 `importedCard`，不自动替换小手机预设或向既有会话插入开场白。放置角色时自动导入并绑定内嵌世界书。
- **世界书**：设置 → 世界书，导入酒馆 JSON（对象或数组条目）或角色书格式。支持常驻、主／次关键词、四种次关键词逻辑、带标志正则、大小写、整词、概率、角色与深度等基础映射。高级递归、扫描预算、冷却、分组、outlet、作者注释等未完全复现，导入详情会提示，原始字段保留。
- **排序**：世界书列表、预设列表和世界书条目都有拖动手柄，支持鼠标／触屏，以及聚焦手柄后按上下键。世界书条目排序同时更新插入顺序，插入位置／深度仍优先决定其所在区域。预设内部条目也支持手柄拖动及方向键，继续保留原有触屏长按和多选排序。
- **模型**：选择服务商、接口协议、地址、模型。支持 OpenAI 兼容聊天、Anthropic Messages 和 Gemini 原生接口；后两者可独立配置中转地址。增加 Mistral、xAI、Ollama、LM Studio 地址模板。本地接口可选“无需 API Key”；模型名称可手填；可配置请求头。旧连接默认沿用原有协议判定，不强制迁移。
- **Vertex AI**：服务商选 Google Vertex AI，默认完整模式。点击“选择服务账号文件”导入 Google Cloud 服务账号 JSON；手机无法选择文件时，可点击“粘贴 JSON”，粘贴完整内容后点“校验并保存 JSON”。成功后自动读取项目 ID（可覆盖），区域填 `global` 或模型支持的区域，直接填写 Gemini 模型 ID 并测试连接。OAuth 换取及缓存访问令牌在本站 Node 服务端完成；支持流式、图片输入与 Gemini 原生工具调用。也可切换 Express 使用 API Key。模型列表需手填，未覆盖 Model Garden 其他厂商协议、向量或图像生成接口。服务账号保存在本机设置中且随设置备份导出，请仅在信任的部署上使用；私钥不写入提示词请求快照。
- **跨域**：普通模型连接可启用“服务端转发”。默认允许常用官方地址。自定义转发域名由部署者在 `MODEL_PROXY_ALLOWED_HOSTS` 中设置，逗号分隔；HTTPS、443 端口、不跟随跳转。用户电脑上的本地模型选择浏览器直连，云端 localhost 不是用户电脑。
- **MiniMax**：语音设置选国内／海外对应账户，填语音 API Key、模型及音色，点击试听。官方合成请求默认走本站服务端，可以切回直连；保留自定义地址并支持填写完整合成端点。显式请求 hex 音频，检查业务错误码和音频有效性。试听在用户手势中解锁播放器，并处理取消／切换时旧请求晚到的问题。

## 边界

- “模型名称任意填写”不等于任意协议都能使用。NovelAI 文本、Horde、Bedrock 特殊鉴权、原生 Text Completion 等未纳入本版；可先用提供上述三种聊天协议的网关。
- Vertex 暂不支持独立微信助手、离线云端代聊／现实桥服务器回复；这些路径会拦截此配置，而不会向云端同步私钥。可为它们单独绑定其他兼容接口。
- 微信助手仍以 OpenAI 兼容聊天为接入范围，新版同步支持无 Key 和自定义请求头；原生 Anthropic／Gemini 会明确提示不支持，不会伪装成功。个人云重放请求走现有机制，未使用真实云账号做端到端测试。
- 手机服务端转发受部署平台执行时长和出网条件影响。MiniMax 音色克隆上传仍走原有路径，本版重点修语音合成与试听。
- 没有使用真实模型或 MiniMax 凭据验证，不保证能解决账户额度、区域不匹配、音色失效或服务商自身错误。测试不会发送付费请求。

## 验证

```sh
npm ci
npm run check:compat
npm run check:weixin
npm run check:push
npx tsc --noEmit
npm run build
```

`check:compat` 覆盖角色卡、PNG、世界书条件、旧连接行为、自定义协议／无 Key、本地地址、MiniMax 业务错误和请求路径，以及 Vertex 签名验证、令牌缓存／到期刷新、区域地址、流式转发和凭据隔离。`check:weixin` 覆盖 385 个提示词组装场景。

开发环境若缺少静态资源，应先拉取完整仓库；本次源码审查使用 sparse checkout，未下载大型模型和部分美术资源，不应直接拿稀疏目录当完整发布包。

### Vertex 测试连接提示“不允许跨站调用”

兼容版已修复反向代理把内部请求地址与浏览器域名比较导致的误拦截；Vertex 和通用模型转发共用同源检查，真正跨站请求仍会拒绝。部署此修复后刷新页面再试。

如果“Google Cloud 项目 ID”一栏误填了整段 JSON，请重新选择服务账号文件，或清空该栏使用账号中的项目。导入时会替换无效项目内容，保留有效的自定义项目 ID；请求发出前也会检查，避免将 JSON 拼进请求地址。模型 ID 仍需填写账号实际可用的 Vertex 模型。测试覆盖代理请求头与字段校验，未使用真实 Google 账号进行付费请求。

### Vertex 504 / Inactivity Timeout

完整模式的请求由本站服务器转发。默认使用原始 JSON / SSE 转发，不额外包裹内部保活协议；原生流式输出仍可使用。此前版本对新客户端强制开启内部保活，尚未充分验证部署适配器对长响应的支持。出现“模型连接提前中断”时，只能确认内部协议未接收完整，不能直接归因为平台超时。

仅在部署环境验证长响应兼容性后，才可设置服务端环境变量 `VERTEX_RESPONSE_TUNNEL=true` 开启实验性保活。关闭或删除该变量后重新部署即可恢复普通转发，已有支持保活的客户端也兼容；无需重填服务账号。保活与普通转发均不自动重试生成或工具动作。

保活不能突破部署平台的最长执行时间，也不能修复 Google 或服务器出网链路自身的超时。Netlify 的具体时限见[官方函数配置说明](https://docs.netlify.com/build/functions/configuration/)，Vercel 见[函数运行时间说明](https://vercel.com/docs/functions/configuring-functions/duration)。仍超时时应结合部署日志判断是平台强制终止还是上游异常。

内置表情包标记由本地解析，不会仅因结尾有表情包就额外请求模型。测试覆盖中文表情、分片 UTF-8、SSE、上游错误状态、取消与中途断线；未用真实 Google 账号验证部署网关的行为。
